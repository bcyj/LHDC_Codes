测量日期：2026-10-22。数据来自本次已经完成验证的 Release 产物；本轮只读取文件和二进制节信息，没有重新编译或改变算法。所有表格使用 KiB（1 KiB = 1024 字节），未压缩。

## 统计口径

- 按 V4 编码、V5 编码、V4 解码、V5 解码、AR 和数学库分别统计；V4 包含 LLAC，编码统计包含各自 BT 包装。
- 公共数学、DSP、内存/缓冲和平台支持单列，未重复归入每个编解码模块。静态库表是对象归档大小，不包含其外部依赖。
- 静态对象节在最终链接前尚未进行按需抽取、COMDAT 合并及死代码删除，不能直接视为最终 EXE、DLL 或 SYS 的增量。
- “可写”包括初始化数据与 BSS，不包含实例工作区、堆、栈、加载器页对齐及系统 CRT。实例内存应使用公开工作区查询接口测量。
- 不包含 PDB 文件。NDK 的静态归档可能含调试信息；代码与数据节统计不含这些调试信息。

## 使用这些数字

选择单独模块时，除模块自身外还要链接所需公共支持。只需要编码或解码的应用，应使用组件目标和对应构建开关；最终应用的体积取决于实际调用入口和链接器裁剪。AR 的卷积/HRIR 等只读系数是其只读数据的重要组成部分，不能按纯算法指令大小估算整个效果器。

本统计基于普通 SDK/Android 默认配置，V5 定点编码 FFT、非递归浮点 FFT和调试日志均关闭。它不是零 CRT 或 SYS 配置的体积结果。
