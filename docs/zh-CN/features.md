# 功能说明

[English](../features.md) | 简体中文

本说明对应本目录源码。接口声明以随附公开头文件为准；编解码版本、实例句柄和工作区不能混用。

## 组件能力

| 组件 | 功能 | CMake 目标 | 公开头文件 |
|---|---|---|---|
| 编码器 | V4 LHDC/LLAC、V5 PCM 编码；帧封包、码率及 MTU 配置 | `lhdc::encoder` | `<lhdc/encoder/lhdc_bt.h>` |
| 解码器 | V4 LHDC/LLAC、V5 有损帧解析、频谱重建、时域合成及 PCM 写出 | `lhdc::decoder` | `<lhdc/decoder/decoder.h>` |
| 通用 PCM 接口 | 格式描述、工作区绑定、后端分派及参数传递 | `audio_ar::ar` | `<ar/pcm.h>`、`<ar/backend.h>` |
| LHDC AR | 上混、距离增益、混响、HRIR 卷积和双耳定位 | `lhdc::ar` | `<ar/lhdc_pcm.h>`、`<lhdc/ar/pcm_backend.h>` |
| 公共数学 | 浮点 FFT、FMA、浮点分类、转换、取整、缩放及软件数学函数 | `audio_common::math` | `<audio_math/...>` |
| 公共基础组件 | 无动态分配环形缓冲 | `audio_common::core` | `<audio_common/ring_buffer.h>` |

编码器、解码器和 AR 可按需组合。AR 直接处理 PCM，可用于编码前、解码后，或作为独立音效链。

## 编码器

### V4 与 LLAC

V4 编码组件包含 LHDC 及 LLAC 低延迟路径，提供创建、初始化、编码、码率调整和销毁接口。

- BT 包装接受 44.1/48/96 kHz 配置；具体组合仍由对应编码核心校验。
- 通过 `lhdcBT_get_handle()` 选择版本，通过 `lhdcBT_get_block_Size()` 查询每帧输入采样数。
- `lhdcBT_encodeV3()` 返回输出字节数及帧数；`lhdcBT_encode()` 是单帧 LHDC 调用，不能用于 LLAC。
- 支持质量档位、最高码率限制、发送队列反馈和 MTU/调度间隔配置。
- 普通 LHDC 的质量预设可通过 `<lhdc/encoder/v4/quality_presets.h>` 按实例查询和修改。

### V5

V5 BT 包装接受 44.1/48/96/192 kHz、16/24/32 位 PCM，初始化为 5 ms 帧。32 位是输入容器格式，不能据此推断有效音频精度为 32 位。

- `lhdcv5BT_get_handle()` 创建实例；`lhdcv5BT_init_encoder()` 配置格式、质量、MTU 和间隔。
- `lhdcv5BT_encode()` 接收输入和输出容量，返回输出字节数及帧数。
- 提供固定质量档位、码率上下限、按队列反馈的 ABR，以及 META/AR 扩展参数接口。
- 可通过 `LHDC_V5_ENCODER_FIXED_FFT=ON` 在 MDCT 内启用定点 FFT，默认关闭。窗函数、前后旋转和其余编码链仍为浮点，不是全链路定点编码器。
- `LHDC_BT_USE_AOSP_REFERENCE` 保留另一组 BT 策略实现；本发布版的常规构建固定使用 `0`。默认能力不包括据另一分支推断的完整无损 VBR 流控。

两版 BT 包装属于跨平台的蓝牙编码适配层，不直接接入操作系统的蓝牙发送服务；宿主负责传输编码结果并提交队列反馈。

### 编码 PCM 与帧输入

编码 API 使用双声道交错 PCM；具体位深对应的字节容器、输入块大小和输出容量要求应按所用接口执行。输入采样数从当前实例查询，不硬编码为所有采样率通用的固定长度。元数据和扩展配置使用头文件规定的报文布局。

## 解码器

解码器公开接口是实例接口，不依赖全局单实例。

| 路径 | 主要入口 |
|---|---|
| V4 内存查询、受检初始化 | `lhdc_util_dec_get_mem_req()`、`lhdc_util_init_decoder_in_memory()` |
| V4 帧信息、解码及销毁 | `lhdcFetchFrameInfo()`、`lhdcDecodeProcess()`、`lhdcDestroy()` |
| V5 内存查询、受检初始化 | `lhdcv5_util_dec_get_mem_req()`、`lhdcv5_util_init_decoder_in_memory()` |
| V5 帧信息、解码及销毁 | `lhdcv5_util_dec_fetch_frame_info()`、`lhdcv5_util_dec_process()`、`lhdcv5_util_dec_destroy()` |

V4 公开初始化识别协议版本 200/300/400，版本 500 选择 LLAC；V5 公开初始化版本为 550，帧时长参数使用 `50` 表示 5 ms。查询容量和初始化时必须使用匹配参数。

V5 当前时域链为有损解码路径；`lossless_enable` 参数不启用另一条完整无损解码链。不要仅凭参数或函数名把它当作已支持无损解码的声明。

### 输出格式

- V4 输出交错双声道；16 位使用每样本 2 字节，其余公开写出路径使用每样本 4 字节槽。
- V5 的 `audio_fmt=0` 为交错双声道，`2` 为单声道平面，`3` 为双声道平面。
- V5 的 32 位输出格式将 24 位有效样本左对齐。
- AR 的紧凑 24 位 PCM 与解码器的 32 位槽不等同。两者连接时由宿主显式转换容器格式。
- 输入应提供完整帧及接口要求的可读尾部空间。帧信息解析接口不替代所有输入容量校验；输出缓冲按当前样本数、位深及声道布局分配。

日志回调按实例注册，初始化后再注册，重新初始化后须重新注册。关闭日志编译选项时不执行日志格式化或回调。

## AR PCM 效果器

通用 `ArPcm` 接口只定义格式、工作区和后端回调。默认后端为 LHDC AR 的 V5 参数组，也可通过 `<lhdc/ar/pcm_backend.h>` 显式选择 V4/V5 参数组，或接入自行实现的 `ArPcmBackend`。

LHDC 后端的约定：

- 小端交错双声道 PCM，支持 16/24/32 位；24 位使用连续三个字节。
- 支持 44.1/48/88.2/96 kHz；单次最多处理 256 个采样帧。
- 工作区要求 16 字节对齐，按查询容量分配。
- 支持原地处理或独立输入输出；成功时输入输出字节数相同。
- 可读写效果参数并设置陀螺仪方位，角度单位为十分之一度。
- 初始化和处理不取得调用方工作区所有权。

通用接口也可通过 `AR_DEFAULT_BACKEND=NONE` 独立构建，由每个实例显式提供后端，无需链接 LHDC 算法。

## 实例内存与并发

编码实例支持三种存储方式：默认用户态分配器、`*_get_handle_with_allocator()` 宿主回调、`*_get_handle_in_memory()` 调用方工作区。使用 `*_workspace_bytes()` 查询当前构建所需容量。

解码器和 AR 使用显式工作区。工作区大小可能随 ABI、构建选项和实现变化，禁止使用内部结构大小或旧版本常量代替公开查询。编码实例和受检解码初始化要求的基址对齐为 16 字节。

`LhdcAllocator` 在 `<lhdc_memory.h>` 中声明。分配接口复制回调表；其 `context` 及宿主资源必须覆盖全部关联实例的寿命。内存池 `LhdcMemoryArena` 用于实例初始化阶段顺序分区，不提供子块逐项回收。

不同实例的音频状态相互隔离；同一个实例的配置、处理、日志回调变更和销毁须由宿主串行安排。只读数学表共享存储，音频历史及临时缓冲由实例持有。

## 数学与变换

同级 `audio_codec_common/math/` 模块不依赖 LHDC 类型、内存分配器或日志，可供其他编码库共用。公共浮点 FFT 不分配内存；调用方提供输入、输出、旋转表和必要的通用基数临时区。支持递归调度，以及可选的非递归静态调度。受支持的 x86/x64 目标默认启用二进制一致 SSE2 蝶形；面向 AR 性能测试的非二进制一致 split-radix SSE 后端保持为独立可选路径。

同级 `audio_codec_common/core/` 模块提供无动态分配的公开环形缓冲实现。LHDC 仅保留兼容接口，存储和索引操作由公共实现完成。

LHDC 公共 DSP 进一步提供 DCT-IV 与定点 FFT。数值函数按头文件规定处理范围、舍入、饱和或模运算，不作为完整 C99 `libm` 替代品，也不统一保证 CRT 的 `errno`、浮点异常标志或任意舍入模式。

默认／可选后端策略、受影响热点及验证要求见[性能优化说明](performance-optimizations.md)。

## 平台范围

- Windows：MSVC/MSBuild Win32/x64；Win32 默认使用 SSE2，数值构建保持严格浮点配置。
- Android：NDK ARM32/ARM64；提供分版编码、BT 包装及解码 SO，日志通过 Android 后端接入。
- Windows 驱动：随附显式内存回调及 WDK nonpaged pool 适配源码。资源约束选项不等于完整 `.sys` 驱动，宿主仍负责浮点状态、执行上下文、调用栈及链接依赖。

本目录不包含蓝牙栈、音频文件解析器、播放器、CSV 参数加载器或完整驱动工程。
